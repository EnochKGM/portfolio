# Enoch K — Creative Portfolio

A dark, editorial, glassy portfolio for Enoch K.

## Personalization

- Replace `assets/profile-placeholder.svg` with your own portrait, such as `assets/face.jpg`.
- Update the `<img>` source in `index.html` if you use a different filename.
- Add your resume as `assets/resume.pdf` and update the Resume button link.
